# 🚘 Araç Kiralama Sistemi (Masaüstü Uygulaması)

🚧 **Durum:** *Bu proje şu an aktif olarak geliştirilmektedir (Work in Progress).*

Görsel programlama dersi kapsamında geliştirilen bu proje, C# Windows Forms kullanılarak tasarlanmış kapsamlı ve veritabanı destekli bir araç kiralama sistemi masaüstü uygulamasıdır. Kullanıcıların araçları inceleyebileceği, kiralama yapabileceği ve yöneticilerin sistemi kontrol edebileceği, tüm verilerin güvenli bir şekilde veritabanında tutulduğu dinamik bir yapı hedeflenmektedir.

## 🌟 Geliştirme Süreci ve Özellikler

Aşağıdaki özellikler proje kapsamında adım adım geliştirilmektedir:

- [x] Temel form tasarımlarının ve UI arayüzünün oluşturulması
- [ ] Veritabanı mimarisinin (Tablolar, İlişkiler) kurulması ve bağlantıların sağlanması
- [ ] Kullanıcı kayıt ve giriş (Login) akışlarının veritabanı bağlantılı entegrasyonu
- [ ] Müsait araçların sistemden çekilip dinamik olarak listelenmesi ve filtrelenmesi
- [ ] Araç kiralama ve rezervasyon işlemleri
- [ ] Admin (Yönetici) yönetim paneli üzerinden araç ve kullanıcı kontrolü

## 💻 Kullanılan Teknolojiler

- **Dil:** C#
- **Platform:** .NET Framework / Windows Forms (Masaüstü)
- **IDE:** Visual Studio
- **Veritabanı:** MSSQL / SQLite / MySQL 

## 🚀 Kurulum

Proje henüz geliştirme aşamasında olduğu için tam kurulum adımları ve veritabanı yapılandırma dosyaları (SQL script vb.) daha sonra eklenecektir. Kaynak kodları incelemek için projeyi Visual Studio üzerinden açabilirsiniz.
